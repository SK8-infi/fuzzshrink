\abstract{Dastkhan, Mosaffa and Fabozzi (2026) combine fuzzy clustering, an LSTM forecaster and a genetic algorithm into a portfolio framework and report that \$1,000 grew to \$5,344 in 2024, with a Sharpe ratio of 11.93 against 0.31 for the Nasdaq-100. We test these claims on the same stocks and cost assumptions, using a reconstruction of the pipeline and protocols fixed before each computation. The published performance table does not agree with itself. Its reported returns exceed those implied by its own final-wealth figures, and its benchmark rows mix monthly and annual units. By the paper's own formula, the Nasdaq-100's 2024 Sharpe ratio is 2.30. The reported 1.67\% price error is higher than that of a random walk (1.38\%), and the LSTM's return forecasts carry no information about which stocks will outperform. Choosing the configuration on the test year, as the paper did, roughly doubles the 2024 result compared with choosing it on 2023. Over 2019--2024, with the configuration re-chosen each year, the pipeline does earn high returns, but it does so by holding about three stocks at 2.3 times the index's volatility. Its Sharpe ratio of 0.97 matches the index (0.93) and trails an equal-weighted portfolio of the same stocks (1.05). Each module raises returns, yet none of the module contributions is statistically significant. The framework's apparent advantage reflects risk and reporting choices more than forecasting skill.}
